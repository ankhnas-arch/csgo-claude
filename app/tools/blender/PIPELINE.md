# Blender weapon pipeline (bpy 4.5.14 LTS, headless Python module)

Tool route: `python3` with the `bpy` PyPI module (Blender 4.5.14 LTS). No Blender GUI, no BlenderMCP (port 9876 was
probed and is not running; this route replaces it). All authoring is scripted and reproducible.

## Conventions (must match `src/render/viewmodel.ts` / `src/render/scene.ts`)
- Units: metres. Real-ish sizes: AK-47 ≈ 0.88 m long, M4A4 ≈ 0.84 m, AWP ≈ 1.2 m, USP-S ≈ 0.20 m (0.27 with suppressor), knife ≈ 0.28 m.
- Axes in Blender: muzzle points **+Y**, up is **+Z**, right side of the weapon is **+X**. glTF export converts to three.js (+Y → -Z forward). Never rotate the root to compensate.
- Root: an Empty named `weapon` at the origin. The origin sits at the **rear of the pistol grip / trigger area** (where the firing hand is), so the weapon extends forward (+Y). Viewmodel code places this origin at camera-relative (0.14, -0.16, -0.33).
- Required named objects (children of `weapon`): `receiver` (main body; for pistols `frame`), `mag` (detachable magazine, origin at its top/insertion point), `bolt` (AK/M4 charging handle+bolt carrier; AWP bolt handle; pistols name the slide `slide`), `trigger`, `stock` (rifles), `scope` (AWP), `handguard`, `barrel`. Knife: `blade`, `handle`. Grenades are not part of this task.
- Required empties: `muzzle` at the barrel tip (+Y end), `eject` at the ejection port. Both children of `receiver`.
- Hands/arms: rigid-part hierarchy under an empty `arms`: `arm_R` (forearm+sleeve), `hand_R` (palm), fingers `fR_1..fR_4` + `thumb_R` (2 segments each is enough), same for left (`arm_L`, `hand_L`, `fL_*`). Gloved (dark polymer/leather material) with a sleeve cuff. Right hand grips the pistol grip with index finger on the trigger; left hand supports handguard (rifles) / cups the slide-frame (pistol) / holds the knife freehand. Contact must stay plausible during every animation (animate finger/palm empties together with `mag`, `bolt`).
- World/drop variant: an object named `world` (child of `weapon`) — a decimated single-mesh copy of the gun (no arms), hidden in viewmodel by code. Target ≤ 1500 tris.
- Animation: ONE scene timeline at 30 fps containing all clips back-to-back; export `export_animation_mode='SCENE'` so the GLB has a single animation. Write `<id>.anim.json` next to the GLB with clip ranges (frames, inclusive start / exclusive end) and event markers:
  `{ "fps":30, "clips": { "idle":[0,60], "equip":[60,90], "fire":[90,102], "reload":[102,180], "inspect":[180,280], "rechamber":[280,316] }, "events": { "reload_mag_out": 120, "reload_mag_in": 150, "reload_end": 180 } }`
  Required clips: idle (subtle breathing/sway), equip (weapon rises from below-right into pose), fire (recoil kick + bolt/slide cycle), reload (mag out → new mag in → charge), inspect (turn the weapon to show both sides), and for the AWP `rechamber` (bolt lift/pull/push/lock, ~1.2 s). Knife: idle, equip, fire (slash), fire2 (stab), inspect. Pistols: slide locks back on `fire` is not required; `reload` drops mag and racks slide.
  The game scales clip playback to the rules durations (AK reload 2.43 s etc.), so author natural timing.
- Materials: Principled BSDF only (exportable). Separate materials: `metal_blued` (receiver/barrel, roughness ~0.45, metallic 1, dark blue-grey), `polymer` (grips/handguard, roughness 0.7, metallic 0), `wood` (AK stock/handguard, baked wood-grain texture), `steel_bright` (bolt/edges, roughness 0.3), `rubber` (butt pad), `glove`, `sleeve`, `glass` (AWP lens, dark with slight emission). Bake a 1024² base-color + roughness texture for `receiver`, `stock`, `handguard`, `mag` from procedural noise (scratches/edge wear/wood grain) with Cycles (CPU, 16 samples, Smart UV Project margin 0.02); other parts use plain values. Pack images into the .blend and let the glTF exporter embed them.
- Geometry quality: shaped receiver (not a plain cube: bevelled, with ejection port cut, rail/sight blocks), curved handguard, magazine curve (AK banana mag), front sight post, rear sight, pistol grip with finger swell, stock with butt pad, muzzle device. Use bevel modifiers (segments 2-3) and smooth shading with auto-smooth (`bpy.ops.object.shade_smooth_by_angle` 30°). Target triangle budgets: AK 14k, AWP 16k, M4A4 12k, USP-S 6k, knife 2k, arms 6k (viewmodel version).
- Export: `bpy.ops.export_scene.gltf(filepath=..., export_format='GLB', export_apply=True, export_animations=True, export_animation_mode='SCENE', export_yup=True, export_image_format='AUTO', export_texcoords=True, export_normals=True, export_materials='EXPORT')`. GLB ≤ 3 MB each.
- Renders for review (Cycles CPU 32 samples or EEVEE, 1280×720, neutral grey studio with a 3-point light): `evidence/blender/<id>_side.png`, `<id>_front.png`, `<id>_threequarter.png`, `<id>_fp.png` (camera at the viewmodel pose: camera at (-0.14, 0.33, 0.16) relative to `weapon`, looking along +Y with 62° vertical FOV → shows lower-right composition), and for AK & AWP a 24-frame turntable `evidence/blender/<id>_turntable_##.png` and animation strips `evidence/blender/<id>_anim_<clip>_##.png` (4 frames each).
- Save: `assets-source/blender/<id>.blend` (source, packed textures), script `tools/blender/build_<id>.py` (fully regenerates the .blend and GLB from scratch when run: `python3 tools/blender/build_<id>.py`), and `tools/blender/common.py` for shared helpers (materials, hands, bake, export, render).
- Record in `tools/blender/BUILD_LOG.md`: Blender version, tri counts per object, materials count, texture sizes, GLB size, render times, and every correction pass with what was wrong and what changed.
